## 📚 Documenti Disponibili

### [NUMPY_ARRAYS.md](NUMPY_ARRAYS.md)

**Architettura degli Array NumPy per Modelli N-grammi**

Documentazione completa sulla scelta, creazione e utilizzo degli array NumPy:

- 🎯 **Motivazione**: Perché NumPy invece di CSV/dizionari
- 🏗️ **Architettura**: Struttura, dimensioni, dtype
- 🔧 **Creazione**: Pipeline di generazione, smoothing, popolazione
- 📂 **Organizzazione**: File NPY, metadata, relazione con CSV
- 💼 **Utilizzo**: Caricamento, scoring, esempi pratici
- ⚡ **Performance**: Benchmark, ottimizzazioni, memory footprint
- 🔤 **Alfabeti**: Supporto base-26 e base-25 (Playfair)
- 🧪 **Esempi Avanzati**: Validazione, analisi, confronti

**Quando consultare**: Essenziale per comprendere il formato output e implementare scoring Vigenère/Playfair.
